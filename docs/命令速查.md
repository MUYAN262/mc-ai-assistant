# 命令速查

## 玩家命令（`PermType.Any`）

| 命令 | 别名 | 说明 |
|---|---|---|
| `/ai 菜单` | `/ai menu` | **图形菜单**，所有功能都在里面 |
| `/ai 购买 <分钟>` | `/ai buy` | 买服务时长，20 金币/分钟，最少 10 分钟、最多 240 |
| `/ai 召唤` | `/ai spawn` | 把助手叫到身边（需要有效服务） |
| `/ai 过来` | `/ai come` | 让助手走到你身边（常驻模式免费可用） |
| `/ai 去 <x> <y> <z>` | `/ai goto` | 走到坐标，超过 48 格会被拉回上限 |
| `/ai 跟随` | `/ai follow` | 跟随你，距离超过 3 格才重新寻路 |
| `/ai 停下` | `/ai stop` | 原地待命 |
| `/ai 跳` | `/ai jump` | 跳一下 |
| `/ai 看向我` | `/ai look` | 转头看你 |
| `/ai 上来` | `/ai up` | 强制上浮出水（卡在水里时用） |
| `/ai 自动攻击 on\|off` | `/ai attack` | 每秒扫描半径 6 格内的敌对生物自动攻击（不打玩家） |
| `/ai 自动放置 on\|off` | `/ai place` | 每秒用手里的物品放方块 / 吃东西 |
| `/ai 诊断` | `/ai diag` | 打印余额、经济接口、寻路探测、xuid，排查用 |
| `/ai 改名 <新名字>` | `/ai rename` | 给**自己的**助手改名（1-8 字，不能用纯数字） |
| `/ai 剩余` | `/ai balance` | 看剩余服务时间 |
| `/ai 离开` | `/ai leave` | 让助手离场 |
| `/ai 帮助` | `/ai help` | 命令列表 |

## 聊天触发

在游戏内聊天里以触发词开头即可，默认触发词：`小把罢`、`@小把罢`、`小把`、`小鲸`、`!ai`。

```
小把罢 过来
小把罢 购买 30
小把罢 改名 小蓝
小把罢 下界合金怎么弄
小把罢 你能刷物品吗
```

被叫到但只想闲聊时会走模型回答；问能力边界会明确说「没有管理员权限」。

## 管理员命令（`PermType.GameMasters`）

| 命令 | 说明 |
|---|---|
| `aiadmin status` | 在线助手、付费玩家、key 状态、常驻是否就位 |
| `aiadmin grant <玩家> [分钟]` | 加时长，省略分钟默认 30 |
| `aiadmin spawn <玩家>` | 给某玩家召唤助手 |
| `aiadmin dismiss <玩家>` | 解散某玩家的助手 |
| `aiadmin rename <新名字>` | 给常驻助手改名（**控制台不能输中文**） |
| `aiadmin selftest` | 自检：key、白名单、危险调用扫描、扣费逻辑 |

- `aiadmin navtest` —— 寻路自检：让助手从当前位置走到 +16 格，把路径长度与逐秒位置写进 `logs/audit.log`

## 注意事项

- **控制台传中文会变成 `??`**：`aiadmin rename 小蓝` 在控制台执行会把名字写成 `??`。
  中文名请在游戏内用 `/ai 改名 小蓝`，或改 `data/names.json` 后重启。
- `aiadmin grant` 只对**在线**玩家生效；离线授予要改 `data/service.json` 再重启。
- 改名的实现是「断开旧实体 → 原地生成新实体」，会有一瞬间的进服/退服播报。
- 一个玩家同时只能有一只专属助手；常驻那只始终存在（`resident.enabled` 为 true 时）。
