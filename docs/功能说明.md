# 小把罢 AI 助手 · 功能说明

> 版本 v1.7.0 ｜ 2026-11-07 ｜ 适用：主服 `E:\bds`（LeviLamina 26.51.9 + LSE nodejs）
> 插件路径：`E:\bds\plugins\ai-assistant\`

---

## 一、这是什么

一个**住在服务器里的假人玩家**。它是个真正会被 `spawnSimulatedPlayer` 生成出来的实体：有血条、会走路、会寻路、会掉进水里、会说话。玩家可以花钱雇它跟着自己，也可以白嫖公共那只聊天。

它有三个身份，对应三套代码：

| 角色 | 位置 | 说明 |
|---|---|---|
| 游戏内插件 | `E:\bds\plugins\ai-assistant\ai-assistant.js` | 生成假人、走位、自动战斗、说话、调模型 |
| 群桥接子插件 | `E:\bds\plugins\QQMCBridge\mods\ai-assistant\` | 处理群里的只读命令、FAQ，把消息交回机器人 |
| 机器人侧网关 | `...\python-adapter\qqmc\gateway\ai.py` | 真正调模型、管人格、发 QQ |

## 二、玩家能看到的功能

### 1. 公共常驻助手「小把罢」（免费）

- **一直都在**，不需要购买，进服就能看见它在场上。
- **免费聊天**：10 分钟内最多 30 次提问。
- **免费指挥**：叫它过来、跟随、停下、跳、看向我、去坐标。
- **会主动说话**（v1.7.0 新增）：
  - 旁听搭话：别人聊天它不吭声太无聊，**45% 概率**顺口接一句（两次之间至少隔 25 秒）。
  - 自言自语：持续 **2.5～6 分钟**没人理它，它会自己嘟囔一句（10 分钟最多 8 次）。

### 2. 专属助手（付费）

| 项目 | 数值 |
|---|---|
| 单价 | **20 金币 / 分钟** |
| 最短购买 | 10 分钟 |
| 最长购买 | 240 分钟 |
| 同时在场 | 最多 3 只 |
| 问答额度 | 10 分钟 30 次 |
| 到期 | 自动退场并提示续费 |

专属助手可以**单独改名**（1–8 字），别人叫它不会应。

### 3. 它会的动作

只做这些，别的都不会（反作弊白名单，见第六节）：

- 走到指定位置（原版寻路，最远 **48 格**）
- 跟随玩家（距离超过 3 格才动，靠近了会转头看你）
- 停下 / 原地待命 / 跳 / 看向某人
- **水里自救**（v1.7.0 新增）：掉进水里会持续上浮（250ms 一跳，最长 10 秒），寻路目标自动抬高，不会永远卡在水底

## 四、群聊联动

群里和游戏里是**双向**的：

| 方向 | 效果 |
|---|---|
| 群里说话 → 游戏 | 带 `[QQ群]` 前缀广播到游戏内 |
| 游戏聊天 → 群 | 带 `[游戏]` 前缀发到群 |
| **小把罢说话 → 群**（v1.7.0） | 它在游戏里说的每句话（回答/搭话/自言自语）都同步进群 |
| 进服 / 退服 / 死亡 | 群里有提示 |
| 群友进服 | 机器人会主动接一句 |

群里还能问它只读信息：`帮助`、`在线`、`状态`、`时间`、`余额`、`查 <名字>`、`公告`（仅管理员）。

## 六、安全边界（反作弊）

**动作白名单**（只有这 10 个能对假人调用）：

```
simulateMoveTo  simulateNavigateTo  simulateLookAt  simulateStopMoving
simulateJump  simulateSneak  simulateAttack  simulateInteract
simulateUseItem  simulateSwing
```

不在白名单里的 `simulate*` 一律拦截，并写 `[GUARD]` 审计。

**模型的权限边界**：

- 模型输出只走 `mc.broadcast`（纯文字），**无法**触发任何游戏指令。
- 没有任何管理员能力：不给物品、不改游戏模式、不开创造、不刷钱、不传送人、不拆建方块。
- 玩家要求这些时它会用自己的人设拒绝。
- 不编造在线人数、TPS、价格、地址（这类数据由插件注入，不由模型猜）。

## 八、配置速查（`E:\bds\plugins\ai-assistant\config.json`）

```jsonc
{
  "price":   { "perMinute": 20, "minMinutes": 10, "maxMinutes": 240, "currency": "金币" },
  "limits":  { "chatPer10Min": 20, "maxAssistants": 3, "followStopDistance": 3.0, "maxMoveDistance": 48 },
  "resident": {
    "enabled": true,
    "name": "小把罢",
    "freeChat": true,
    "allowMove": true,
    "chatPer10Min": 30,              // 公共助手问答额度
    "spawn": { "x": 394, "y": 128, "z": 1942, "dim": 0 },
    "chatter": {                     // 主动说话
      "enabled": true,
      "chance": 0.45,                // 旁听搭话概率（想更吵调到 0.7）
      "idleMinMs": 150000,           // 自言自语最短间隔
      "idleMaxMs": 360000,           // 最长间隔
      "interjectCooldownMs": 25000   // 两次搭话最小间隔
    }
  },
  "triggers": ["小把罢", "@小把罢", "小把", "!ai"],
  "mirrorToQQ": true                 // 它说的话是否同步进 QQ 群
}
```

**调音量**：嫌吵 → `chance` 降到 0.2、`idleMinMs` 加到 300000；嫌少 → `chance` 提到 0.7、`idleMinMs` 降到 60000。改完需重启主服。

## 十、常见问题

**买不了服务？**
跑 `/ai 诊断`，它会直接告诉你：`player.getMoney` 能不能用、LLMoney 导出有没有、你余额多少。最常见的两个原因是**余额不足**（默认新玩家 0 金币）和**经济插件没接上**。

**叫它不动？**
`/ai 诊断` 看寻路是否可用；审计里出现 `STALL 卡住` 说明被方块挡住。它卡住 5 秒会跳一下，14 秒才放弃（在水里不会放弃，会一直上浮）。

**卡在水里？**
v1.7.0 已修：掉进液体自动持续上浮。手动兜底用 `/ai 上来` 或菜单里「上浮/出水」。

**话太少？**
v1.7.0 已改：会旁听搭话 + 自言自语，问答额度从 12 次提到 30 次。要更吵改 `chatter.chance`。

**群里看不见它说话？**
v1.7.0 已修：新增 `POST /qqmcbridge/say` 通道，它在游戏里说的每句话都会推给群（`mirrorToQQ: true`）。

**它会不会乱来？**
不会。动作白名单 + 模型输出只走广播文字，`/aiadmin selftest` 可随时自检。
