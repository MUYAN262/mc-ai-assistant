# 部署

## 1. 环境

| 项目 | 版本要求 | 本项目验证版本 |
|---|---|---|
| BDS（Bedrock Dedicated Server） | 1.26.x | 1.26.51.1 |
| LeviLamina | 26.51.x | 26.51.9 |
| LegacyScriptEngine | 0.22.x | 0.22.4（nodejs 引擎） |
| 经济插件 | 提供 `getMoney` / `reduceMoney` 或 `LLMoney` | 服务器自带 LegacyMoney |

检查 nodejs 引擎是否装好：`plugins/legacy-script-engine-nodejs/` 目录存在，且服务器启动日志里有
`[legacy-script-engine-nodejs]` 的加载记录。

## 2. 放文件

```
<服务器根>/
  plugins/
    ai-assistant/
      ai-assistant.js          <- 来自本仓库 plugin/
      manifest.json            <- 来自本仓库 plugin/
      config.json              <- 复制 config.example.json 后修改
      llm.key                  <- 一行模型密钥（不要提交到版本库）
      data/                    <- 运行时自动生成
      logs/                    <- 运行时自动生成
```

`manifest.json` 必须和目录同名（`ai-assistant`），否则 LSE 不认。

## 3. 配模型

任何 OpenAI 兼容的 `/chat/completions` 都行，三种常见写法：

**本地 wb-proxy**

```jsonc
"llm": {
  "url": "http://127.0.0.1:8788/v1/chat/completions",
  "model": "deepseek-v4.1-flash"
}
```

**官方 API**

```jsonc
"llm": {
  "url": "https://api.deepseek.com/v1/chat/completions",
  "model": "deepseek-chat"
}
```

**自建网关（OneAPI / new-api 等）**

```jsonc
"llm": {
  "url": "http://127.0.0.1:3000/v1/chat/completions",
  "model": "gpt-4o-mini"
}
```

密钥写在 `plugins/ai-assistant/llm.key`，**一行、不带引号、UTF-8 无 BOM**。
也可以用环境变量 `AI_KEY_FILE` 指向别的文件。

## 4. 首次启动检查

重启服务器，看 `logs/audit.log`：

```
[START] ai-assistant v1.2.0 已加载：价格 20/金币 每分钟，助手 小把罢（可改名），常驻 小把罢，动作白名单 5 项
[RESIDENT] 常驻助手 小把罢 已就位 @ 394,128,1942
```

- 没有 `[START]` → 插件没加载，看服务器日志里 `ai-assistant` 的报错
- 有 `警告：模型 key 未加载` → `llm.key` 路径或内容不对
- 没有 `[RESIDENT] 已就位` → 出生点定位失败，在 `config.json` 的 `resident.spawn` 里写死坐标

再跑一次自检：

```
aiadmin selftest
```

它会检查：模型 key、`mc.spawnSimulatedPlayer` 是否存在、动作白名单里有没有危险动作、代码里有没有
`give` / `setGameMode` / `addItem` / `setHealth`、以及扣费逻辑（用桩玩家模拟一次购买）。

## 5. 经济接口

插件按顺序尝试：

1. `player.getMoney()` / `player.reduceMoney(n)`（LSE 0.22.4 原生导出）
2. `ll.import('LLMoney', 'LLMoney_Get' / 'LLMoney_Reduce')`（LegacyMoney）

两样都没有时，购买会直接失败并提示「读取不到你的余额」，不会白送时长。

## 6. 常驻助手的出生点

`mc.getSpawnPoint()` 在 LSE 0.22.4 **不存在**（调用抛 `mc.getSpawnPoint is not a function`），
所以定位顺序是：

1. `mc.getOnlinePlayers()[0].pos`（有玩家在线时用他的位置）
2. `config.json` 的 `resident.spawn`

想固定在一个地方，就把 `spawn` 写成你自己的坐标；`dim` 是维度（0 主世界 / 1 下界 / 2 末地）。

## 7. 升级

1. 备份 `plugins/ai-assistant/data/` 和 `config.json`
2. 覆盖 `ai-assistant.js` 和 `manifest.json`
3. 重启服务器

`data/` 里的服务时长和名字是纯 JSON，跨版本兼容；配置新增字段会自动用默认值补齐。

## 8. 卸载

删除 `plugins/ai-assistant/` 目录并重启。已经在场上的模拟玩家会随服务器关闭消失。
